## 🌟 Key Features

- **Multi-Page Architecture**: Well-structured, dedicated pages for comprehensive presentation:
  - `index.html`: Engaging hero section, elevator pitch, and fast navigation.
  - `about.html`: Detailed background, values, educational journey, and vision.
  - `experience.html`: Professional leadership, operations, and technical roles.
  - `ventures.html`: Deep-dive into entrepreneurial ventures, including BINTH.IN.
  - `skills.html`: Categorized breakdown of engineering, design, and systems proficiencies.
  - `journey.html`: Interactive timeline of key milestones and achievements.
  - `gallery.html`: Visual showcase of events, projects, and activities.
  - `contact.html`: Direct outreach hub with social links, WhatsApp, and email integration.
- **Responsive & Accessible Design**: Seamless layout adaptations across mobile devices, tablets, and high-resolution desktop screens.
- **Interactive UI Components**: Custom hamburger mobile navigation, dynamic animations, and modal interactions powered by vanilla JavaScript.
- **Optimized Assets & Typography**: Integrated Google Fonts (Montserrat), FontAwesome icons, and lightweight custom styling.

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mohdnabeelsid/PersonalPortfolio.git
   cd PersonalPortfolio
   ```

2. **Open the project:**
   - Double-click `index.html` to open it in your browser, or
   - Use VS Code with the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for live reloading.
